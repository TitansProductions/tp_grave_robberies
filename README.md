# TP Grave Robberies

## How to add a dug object

1. Use Spooni Spooner, it is the best script for getting the correct object placements.
2. Spawn `p_gravedug03x` object on the desired grave position (To open the placed object information, select the object by pressing [7] first, click the object and press [TAB].
3. Get & Add the placed object x,y,z,pitch,roll and yaw positions to the desired grave on the configuration file.
